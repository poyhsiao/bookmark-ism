# 书签同步服务用户指南

## 概述

书签同步服务是一个跨浏览器的书签管理和同步平台，帮助用户在不同设备和浏览器之间同步和管理书签。

## 快速开始

### 注册账号

1. 访问服务首页
2. 点击"注册"按钮
3. 填写邮箱地址和密码
4. 验证邮箱
5. 完成注册

### 安装浏览器扩展

#### Chrome 扩展安装
1. 打开Chrome应用商店
2. 搜索"书签同步"
3. 点击"添加到Chrome"
4. 确认安装

#### Firefox 扩展安装
1. 打开Firefox附加组件页面
2. 搜索"书签同步"
3. 点击"添加到Firefox"
4. 确认安装

## 主要功能

### 书签管理

#### 创建书签
1. 在当前页面点击扩展图标
2. 选择"添加书签"
3. 编辑标题和描述
4. 选择分类
5. 添加标签
6. 保存

#### 编辑书签
1. 打开书签管理页面
2. 找到要编辑的书签
3. 点击编辑按钮
4. 修改信息
5. 保存更改

#### 删除书签
1. 在书签列表中找到要删除的书签
2. 点击删除按钮
3. 确认删除

### 分类管理

#### 创建分类
1. 进入分类管理页面
2. 点击"新建分类"
3. 输入分类名称
4. 选择图标（可选）
5. 保存

#### 管理分类层级
1. 使用拖拽功能重新排序
2. 创建子分类
3. 移动书签到不同分类

### 搜索功能

#### 基本搜索
1. 在搜索框输入关键词
2. 按回车键搜索
3. 查看搜索结果

#### 高级搜索
1. 点击高级搜索
2. 设置搜索条件：
   - 标题包含
   - 描述包含
   - 标签匹配
   - 分类筛选
   - 日期范围
3. 执行搜索

### 同步设置

#### 启用自动同步
1. 进入设置页面
2. 找到同步选项
3. 开启自动同步
4. 设置同步频率

#### 手动同步
1. 点击同步按钮
2. 等待同步完成
3. 查看同步状态

## 高级功能

### 导入导出

#### 导入书签
1. 进入设置 > 导入导出
2. 选择"导入书签"
3. 选择文件格式（HTML、JSON等）
4. 上传文件
5. 确认导入

#### 导出书签
1. 进入设置 > 导入导出
2. 选择"导出书签"
3. 选择导出格式
4. 选择导出范围
5. 下载文件

### 分享功能

#### 分享单个书签
1. 在书签上点击分享按钮
2. 选择分享方式
3. 设置分享权限
4. 生成分享链接

#### 分享分类
1. 在分类上点击分享按钮
2. 设置分享权限
3. 选择是否包含子分类
4. 生成分享链接

### 协作功能

#### 邀请协作者
1. 在分类设置中选择"协作"
2. 输入协作者邮箱
3. 设置权限级别
4. 发送邀请

#### 管理权限
- 查看：只能查看书签
- 编辑：可以添加和编辑书签
- 管理：可以管理分类和权限

## 移动端使用

### 移动网页版
1. 在手机浏览器访问服务网址
2. 使用响应式界面
3. 支持触摸操作

### PWA 安装
1. 在支持的浏览器中访问网站
2. 点击"添加到主屏幕"
3. 确认安装
4. 从主屏幕打开应用

## 隐私和安全

### 数据加密
- 所有数据传输使用HTTPS加密
- 敏感信息存储加密
- 支持端到端加密

### 隐私设置
1. 进入隐私设置
2. 配置数据可见性
3. 设置分享默认权限
4. 管理第三方访问

### 账号安全
1. 启用两步验证
2. 定期更换密码
3. 检查登录历史
4. 管理已连接设备

## 故障排除

### 常见问题

#### 同步失败
1. 检查网络连接
2. 重新登录账号
3. 清除浏览器缓存
4. 联系技术支持

#### 扩展无法加载
1. 检查扩展是否启用
2. 重新安装扩展
3. 检查浏览器版本
4. 查看错误日志

#### 书签丢失
1. 检查回收站
2. 查看同步历史
3. 尝试从备份恢复
4. 联系技术支持

### 性能优化

#### 提高同步速度
1. 减少不必要的书签
2. 定期清理重复书签
3. 优化网络连接
4. 使用有线网络

#### 减少资源占用
1. 关闭不需要的功能
2. 调整同步频率
3. 清理浏览器缓存
4. 更新到最新版本
